# Evidencias locales de release

El script `scripts/release/prepare-production-release.ps1` crea aquí una carpeta por ejecución.

Los logs generados no deben subirse automáticamente al repositorio porque pueden incluir rutas, nombres de equipo o datos del entorno. Revísalos, elimina información sensible y copia únicamente las evidencias aprobadas al expediente privado de publicación.
