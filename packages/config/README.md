# @rapa-go/config

Configuraciones compartidas del proyecto RAPA GO V2.0.0.

## Contenido

### `eslint/`
Configuraciones base de ESLint reutilizables por `apps/mobile` y `apps/api`.
Pendiente de implementar cuando se configure el linting del proyecto.

### `typescript/`
Configuraciones TypeScript base.
La configuración principal está en `tsconfig.base.json` en la raíz del monorepo.
Este paquete puede contener configuraciones específicas por tipo de proyecto (browser, node, etc.).
